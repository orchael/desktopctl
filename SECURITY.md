# Security policy

## Supported versions

Security fixes are provided for the latest release and the `main` branch.
Older releases are not maintained. Upgrade to the latest release before
reporting a suspected issue that may already have been fixed.

## Reporting a vulnerability

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/orchael/desktopctl/security/advisories/new).
Include the affected version or commit, a clear reproduction, and the expected
and observed impact. Please avoid opening a public issue or pull request with
exploit details or credentials.

Private vulnerability reporting is being enabled under [issue #281](https://github.com/orchael/desktopctl/issues/281).
The report link may be unavailable until that repository setting is enabled.
Maintainers will assess privately submitted reports and coordinate disclosure
after a fix is available.
